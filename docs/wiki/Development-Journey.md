# 자료의 의미를 나눈 뒤 방문계획으로

## 필요한 것은 환자 수 label과 달랐다

지역 자료는 많았지만 실제 이동진료 환자 수의 정답은 없었습니다. 인구·의료 공급·접근성 proxy를 바로 감독학습의 정답처럼 사용할 수는 없었습니다. 따라서 설명 가능한 다기준 Need Score와 방문계획을 구분해 개발했습니다.

초기 master에는 시군 반복 열, 이전 점수, 비슷한 인구·고령화 지표가 함께 있었습니다. 전체 열을 그대로 더하면 규모와 중복 개념이 결과를 지배할 수 있어 특징마다 역할·단위·방향·proxy 의미를 정했습니다.

## Stage1: 특징에서 semantic component로

최종 Stage1 구성 기록은 30개 active 특징을 19개 semantic component로 묶습니다. 같은 개념의 count·rate·cutpoint를 각각 독립 full weight로 더하지 않고, component 안에서 보완 측정으로 다룬 뒤 축별 가중치를 줍니다.

시군 건강통계는 11개 시군에서 scaler를 맞춘 뒤 읍면동에 연결합니다. 153개 읍면동으로 반복된 값을 독립 관측처럼 fitting하면 읍면동 수가 많은 시군에 암묵적 가중치가 생기기 때문입니다.

## 점수가 바뀌는 이유까지 확인

특징 하나 제거, 중립 대체, cluster 제거, 축 제거, scaler와 정책 가중치 변경을 나눠 민감도를 확인했습니다. 단순 변환만 바꾼 건강통계 후보는 여러 제거 실험을 악화시켜 채택하지 않았습니다.

순위가 바뀌었다는 이유만으로 실패라고 판단하지도 않았습니다. 특정 정책 축을 제거하면 순위 변화는 의도한 반사실일 수 있습니다. 기본 정책의 안정성과 대안 정책의 stress를 구분했습니다.

## Stage2A: 진료과별 점수가 같은 지도를 반복

초기 specialty 점수는 일반적인 농촌성·의료 접근성을 여러 진료과에서 반복했습니다. 일반 의료기관까지의 불리함은 Stage1에 두고, specialty에는 일반 의료 접근 대비 추가 거리를 표현하는 excess를 넣었습니다.

건강·연령도 서비스 공통 효과와 differential을 나눴습니다. 공급률을 더 중심화하면 일부 상관 수치는 좋아졌지만 시군 내부 분리는 좋아지지 않아 sensitivity로 남겼습니다. 의미 있는 공급 정보를 지우는 방법도 배제했습니다.

## Stage2B와 Stage3: 노출·시간·장소

진료과별 부족과 실제 서비스를 받을 수 있는 exposure를 분리합니다. 계절·근무일 등 시간 구조와 후보 장소의 공간 coverage를 연결합니다. 필요도가 높은 지역이라고 모든 날짜·장소에서 같은 서비스를 제공할 수 있는 것은 아니기 때문입니다.

도로·공간 자료가 표현하는 이동과 현장 이동은 다를 수 있습니다. Proxy와 가용성 정보를 함께 두고, 같은 지역을 여러 장소가 커버할 때 단순 합산하지 않도록 계획 단위로 계산합니다.

## Stage4: 좋은 조합과 조건을 만족하는 조합

후보 탐색 후 방문 수·지역별 cap·coverage·형평성 조건을 가진 계획으로 옮겼습니다. 후속 equity 단계는 최소 시군 coverage를 먼저 정한 뒤 high-need 인구 coverage를 다루는 순차 구조입니다.

상한을 이용한 안전한 후보 제외, coverage cut, threshold infeasibility 검사를 추가했습니다. 개선 가능성을 계산적으로 좁히는 절차와 현장 적합성 판단은 끝까지 구분합니다.
