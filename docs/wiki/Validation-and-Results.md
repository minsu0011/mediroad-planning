# 결과와 정책 해석

## Stage1의 안정성

당시 기록에서 30개 특징·19개 component의 기본 정책은 안정성 조건을 충족했습니다. 구성 변경 전후 순위 상관은 약 0.99519였고 Top20은 한 지역이 교체됐습니다. 이는 동일 Need Score 계열의 구성 안정성이지 실제 진료 수요를 맞힌 정확도가 아닙니다.

대안 가중치 정책 일부는 민감한 설정으로 남았습니다. 기본 정책의 결과를 모든 정책 가중치에 확대하지 않습니다.

## Specialty의 분리

당시 specialty 기록의 clinical-block 간 절대상관 중앙값은 약 0.51561입니다. 일반적인 의료 불리함을 여러 과목에서 반복하던 문제를 줄이려는 진단입니다. 상관이 낮다는 것만으로 임상적으로 좋은 진료과 배치임을 증명하지는 않습니다.

Excess-access 제거 시 큰 순위 변화가 생긴 기록은 해당 성분이 진료과 차이를 만드는 데 중요하다는 근거입니다. 이 stress를 통과시키려고 중요한 신호를 제거하지 않습니다.

## 최적화 결과의 의미

Stage4의 gap은 고정된 후보군·목적함수·제약 아래에서의 계산적 범위입니다. 자료가 바뀌거나 목적함수가 달라지면 이전 점수와 직접 비교할 수 없습니다. 방문계획의 제약 충족과 실제 의료 효과 검증을 구분합니다.

실제 환자 수 label, 현장 이동시간·시설 수용성 확인, 정책 가중치에 대한 합의는 남은 과제입니다. 특정 단계의 수학적 조건 통과를 전체 의료사업의 검증 완료로 설명하지 않습니다.
