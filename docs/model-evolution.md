# 단계마다 다른 질문

153개 읍면동 자료에서 Stage1은 중복 특징을 의미 단위로 묶어 Need Score를 만듭니다. Stage2는 일반적 접근성 불리함과 진료과별 부족·exposure를 분리합니다. Stage3는 후보 장소가 포함하는 지역을 연결하고 Stage4는 방문 수·지역·형평성 제약을 만족하는 조합을 찾습니다.

후속 equity 단계에서는 최소 시군 coverage를 먼저 확보하고 high-need coverage를 다룹니다. 좋은 후보를 찾는 탐색과 더 좋은 후보가 남아 있는지 확인하는 상한·하한 계산은 다릅니다.

정책·후보군·목적함수가 바뀐 점수를 직접 비교하지 않습니다. [변경 이유](wiki/Development-Journey.md) · [결과 해석](wiki/Validation-and-Results.md)
